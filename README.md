# Sunlyn Pilates World — Landing Page

Premium Reformer & Cadillac manufacturer · worldwide shipping from Türkiye.
Single self-contained `index.html` (no build step). Leads come in via a WhatsApp quote form.

## Deploy

**Coolify**
- New Resource → Public/Private Repository → pick this repo
- Build Pack: **Dockerfile** (nginx serves `index.html` on port 80) — or **Static**
- Generate Domain → Deploy

**Anywhere static**
Just serve `index.html` (Netlify, Vercel, GitHub Pages, nginx, etc.).
